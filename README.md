# Sea Power · 海空战模拟平台

[在线游玩 · GitHub Pages](https://dns0129.github.io/Sea_Power/) · [源码仓库](https://github.com/dns0129/Sea_Power)

GitHub Pages 使用下方自动发布流程；首次发布需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。之后推送 main 会先运行测试，再发布 dist/。不同域名的浏览器存档相互独立，可通过游戏内 JSON 导出／导入迁移。

原创 2D 海空联合战策略沙盘，参考 [Sea Power 的传感器、海空协同、实时暂停与时间压缩玩法](https://store.steampowered.com/app/1286220/)。包含真实海岸线上的历史单人任务与虚构海域沙盘；装备和胜负条件使用游戏平衡参数，不复用原游戏资源。

## 启动

macOS 双击 `启动海空战.command`，或运行 `npm start`。需要 Node.js 18 或以上，无须安装依赖。打开 http://127.0.0.1:8789；关闭终端或 Ctrl+C 停止服务。端口冲突时使用 `SEAPOWER_PORT=8790 npm start`。

源码在 `dist/`，无需构建。`server.mjs` 仅提供本机静态页面；Sites 使用 `.openai/hosting.json` 发布。

## 0.5 AI 自动对战平台

打开底部或剧本组件的“AI 对战”，载入海空编队、航母航空、反潜搜索或空白预案；也可以在现代试验场／自由沙盘部署阶段选择“使用当前双方部署”。双方分别部署、撤回单位和配置任务挂载，完成后点击“开始 AI 对战”。原有手动模式和三个历史任务继续使用原先的指挥流程。

- 双方各 600 点的预案使用相同现代编队镜像部署，剩余点可自由配置。可分别选均衡协同、积极进攻或谨慎防御；设置 5–240 分钟时限和 0–4294967295 随机种子。自动对战使用固定一秒步长，相同部署、种子与风格产生可重复的结果，暂停与倍速只改变观看进度。
- AI 每八秒指挥一次，自动开启适用传感器、搜索、绕岛、接敌、发射和防御。规划只读取本方单位、公开海岸与本方可使用的有效航迹。深潜数据链限制照常生效；潜艇按通信窗口或本艇声呐观测升至潜望镜深度。失联目标没有隐藏位置更新。
- 制空机拦截，攻击机按适用武器射程接敌；保留防空弹不计入可用进攻射程，半主动武器的接敌距离受本平台照射视距限制。预警、加油、航空舰与补给平台在本方后方支援，电子战机启用干扰。反潜机低空搜索，直升机交替转场与低速吊放搜索，潜艇低速航行。
- 航母及护航舰双方均自动放飞有限机库中的飞机，依航迹选择制空、反舰、反潜等任务。任务弹药耗尽会返航整备；飞机低油可与兼容加油机会合，否则遵循返航规则。航空补给舰会寻找缺货航空舰并低速转移库存。损失、甲板准备、接口、航油、弹药及库存均受原有规则限制。
- AI 接管后单机手动指令锁定；仍可暂停、使用 1/10/30/120×、选择双方单位看 AI 当前任务及保存／载入。全局观察只影响绘制，不更改 AI 航迹；蓝／红视角各显示本方平台及本方接触。
- 一方战斗平台全部损失后等待在途攻击结算；双方无可用攻击弹药或后续架次则提前结算，达到时限必定结束。时限／主动结束按实际有效毁伤点比较：实际损伤 ÷ 平台完整结构 × 部署点，差值小于 0.5 点为平局。未命中的在途武器不计为预期伤害。
- 战报统计双方投入单位（含已放飞飞机）、现存与损失、武器发射（含近防批次）、命中损伤、成功拦截、航空出动与毁伤评分；可导出 JSON。事件保留最近 400 项，界面显示最近 60 项。“同编组重赛”恢复开战前部署、弹药、损伤、挂载、库存与配置，允许再调整后启动。
- v5 存档保留 AI 计划、配置、统计、时间线、时间步余量和初始部署快照；载入默认暂停并可续跑。兼容 v1–v4 战局，旧战局不会自动启用双方 AI。自动对战属于浏览器内的确定性规则模拟，无需外部 AI 服务，不是定时任务。

核心指挥、战报与配置校验在 `dist/auto-commander.js`，引擎负责既有传感器、物理交战及库存。界面在 `dist/auto-battle-ui.js`。此版本仍是游戏战术抽象；预案的镜像编组用于机制对照，不代表真实国家交战计划。

## 0.4 现代装备库

- 任务挂载：制空、反舰、压制、对地、反潜等方案共享飞机载荷额度。舰艇按各型垂发容量分配防空、反潜、对陆等弹药，独立弹库分别计算。隐身机外挂增大可探测特征。部署时可换装；飞机整备时可更改下一架次挂载，不能在空中凭空补弹。
- 航空运用：弹射、滑跃、短距／垂直、直升机甲板按型号适配。舰体部署点包含缩编航空队，放飞不另收费；库存、在空容量、甲板间隔、重伤及航空补给共同限制出动。飞机返回移动母舰整备 240 秒，舰沉导致甲板飞机损失，已损失飞机不能从机库无限再生。红方自动先出动预警机，双方使用相同限制。
- 后勤：飞杆／软管受油接口、会合距离、速度及高度限制空中加油；一次接待一机，供油有限，不补弹药。加油量以续航秒数等效。补给舰在 ≤1.5 nm、双方 ≤12 kn 时以 15 秒／点转移航空补给，不重装舰载垂发。
- 潜艇：现代潜艇声呐可搜索水面和水下目标；深潜不接收外部数据链或使用雷达／电子支援。潜望镜深度可通信和发射潜射导弹，暴露桅杆并开启雷达会增加被探测机会。
- 火力：新增舰炮批次、火箭助飞鱼雷、精确对陆弹药与轻型攻击导弹，共 14 类武器。部分型号显示公开武器家族名称，仍使用共有的游戏弹道模型。Su-33 的半主动空空弹需要持续雷达照射，专职预警／加油机不携进攻武器，075 不运用固定翼战斗机。
- 试验场双方各 600 点，无强制胜负，最多 60 个已生成单位（包含放飞飞机和损失记录）。它使用虚构训练海域；三个历史任务继续使用各自真实海岸线及固定年代兵力。
- v4 存档保留所选挂载、航空队库存、母舰引用、甲板准备、可供燃油与补给目标；兼容 v1/v2/v3。导入会校验弹药、载荷、航空队总数与资源引用。

现代资料与型号配置在 `dist/modern-catalog.js`，引擎在 `dist/engine.js`，目录界面在 `dist/equipment-ui.js`。本版未模拟登陆流程、水雷战、完整甲板调度、全套声学传播、阵营间真实通信协议或战略核武器；现代型号可跨国家自由编组，数据链互通采用游戏抽象。

## 0.3 三个历史单人任务

从“剧本”菜单进入布比延封锁线；“剧本”菜单可选择其他历史任务与原有演练。历史任务固定兵力，无额外部署点，提供任务目标、倒计时、简报来源、任务指令与评分。开始后可暂停并通过按钮或逐单位航点下令。任务指令会设置航线并启用自动交战。

| 任务 | 历史原型与地图 | 单人目标 | 推演时限 |
| --- | --- | --- | --- |
| 布比延封锁线 | 1991 年 1 月 29—31 日布比延岛海战；波斯湾北部 | 击沉至少三艘撤退舰艇，最多允许一艘脱离 | 30 分钟 |
| 萨汉德号遭遇战 | 1988 年 4 月 18 日“祈祷螳螂”行动局部；霍尔木兹海峡与拉腊克岛 | 将目标结构降至 40% 以下，再让水面指挥舰抵达撤离区 | 40 分钟 |
| 圣卡洛斯登陆掩护 | 1982 年 5 月 21 日登陆日；福克兰海峡与圣卡洛斯水道 | 两艘运输船抵达锚地，连续卸载 120 秒，抵御三波空袭 | 35 分钟 |

运输船已设避岸航线；“执行护航”将护卫舰带入水道，战斗机也可手动前出拦截。低空攻击机必须接近投弹，炸弹不会被当作反舰导弹拦截。自动对空交战限制同一目标同时在途的弹数，减少过度消耗。任务按自身目标结算，超时会失败。

新增八类年代／运输平台，以及红外空空弹、自由落体炸弹，共 28 类平台、10 类武器。轻型半主动反舰导弹使用本机雷达照射和平台专属弹头参数；海鹞角色不使用现代主动雷达空空弹。年代型平台是能力近似，不是逐型号数据库。

### 地图与历史边界

三张地图使用 [Natural Earth 1:10m land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_land.geojson) 的公有领域海岸线裁切，数据本地打包，游玩无需连接地图服务。投影以中央纬度的等距圆柱近似，将纬度一度转换为 60 海里，经度按 cos(纬度) 修正；显示真实经纬度与海里比例。水面航行、部署和存档验证都使用所选地图的陆地遮罩。任务航线由网格 A* 搜索并逐段检查海岸相交，避免窄水道停航。

采用现代概化海岸线，没有重建 1980—1990 年代的海图、潮汐、航标、地雷或山地高程。历史任务中的低空岸线遮蔽为平面近似。兵力规模、位置、任务边界、增援波次和时限均有玩法调整；每个简报明确说明。

- [萨汉德战例：NHHC Enterprise 1986—1990](https://www.history.navy.mil/research/histories/ship-histories/danfs/e/enterprise-cvan-65-viii-1986-1990.html)

## 0.2 联合作战与平衡基础

- 20 类平台：驱逐舰、护卫舰、潜艇；多用途、截击、制空、隐身和舰载战斗机；攻击机、预警机、电子战机、海上巡逻机、反潜直升机；岸基亚音速／超音速反舰、远／中／近程防空、对陆巡航导弹阵地和航空补给基地。
- 8 类武器，区分空空弹和舰／岸防空弹；按平台设置射程、最小射程、发射间隔、弹药与火控通道。远距离射击命中率下降。
- 雷达地平线、低中高飞行高度、隐身发现距离折减、电磁暴露、电子干扰、友军数据链、航迹逐步确认和失联记忆。
- 主动导弹的中段航迹更新与末段搜索；区域防空弹持续本机照射；反辐射导弹依据信号接敌，命中后压制雷达。
- 区域导弹 → 近程导弹 → 近防射击 → 诱饵分层自卫。拦截弹实际飞行，通道与弹药有限；保留弹药只限制主动攻击，可用于自卫。
- 航空燃油、固定翼待命盘旋、低油自动返航、手动返航、四分钟补给、有限基地库存；结构损伤不会在补给时恢复。
- 重伤降低航速、雷达效能并延长发射间隔。岸基阵地只能放在陆地且不可移动；双方自由沙盘部署均扣点、可撤回返还。
- 新增“近岸联合行动”剧本。舰队自动交战可按单机或全队开启，蓝方保留玩家航线；红方自主接敌仅使用已探测航迹。
- 保留全屏海图、可拖动和收放的浮动组件、传感器圈、航点、编队、记录、暂停及 1/10/30/120 倍推演。
- 本地战局保存和 JSON 导入／导出；自动迁移 v1 的飞机弹药与在途武器。载入保留失联位置和探测时间，不重新扫描恢复目标。

## 操作

1. 历史任务先查看简报，开始后点击任务指令；在自由部署剧本打开舰队组件，按国家、任务或技术阶段筛选（通用岸基单位位于“通用／历史任务型”系列），再点击海图放置。预设剧本蓝方在 X ≤ 115 海里部署，岸基单位放在西岸；自由沙盘支持双方。
2. 开启雷达或声呐，等待接触从“正在确认”变为“有效航迹”。预警机默认开雷达，能将远方接触共享给开启数据链的友军。
3. 右键设置航点，Shift + 右键追加；也可使用按钮或坐标。飞机可调整高度，低空降低雷达视距；反潜直升机使用吊放声呐时保持低空且 ≤ 40 kn。
4. 选择蓝方平台，再选择红方接触。武器行显示发射条件和阻止发射的原因。可开启单机或全队自动交战，并选择区域防空保留弹药。
5. 留意燃油，提前返航可以加油装弹。部署基地每次补给消耗 ceil(机型部署点 / 4) 点，至少两点；基地共有 30 点。未部署基地时使用后方补给区，每架飞机最多补给两次。
6. 空格暂停／继续，Esc 取消指令；滚轮缩放、拖动平移。底部控制台收放组件，拖动顶栏移动组件；组件收放不影响海图尺寸。
7. “剧本 → 作战机制与平衡”解释探测、制导、资源与单位分工。保存只写浏览器 localStorage，可导出 JSON 跨浏览器迁移。

## 模型与参数边界

坐标为海里，速度为节；移动距离 = 速度 × 推演秒数 / 3600。传感器每三秒更新；单雷达接触通常连续九秒、声呐十二秒确认，多源可加速确认；目视立即确认。六秒未更新后禁止依照该航迹发射，九十秒后删除。电子支援只给粗略位置，但可支持反辐射攻击。

雷达地平线按 2.23 × (√观察高度 + √目标高度) 海里近似；高度以米计。实际雷达范围取地平线、标称范围、天气、损伤、干扰与目标特征折减的较小值。海图橙色虚线圈表示对海几何视距，绿色圈为中空目标的探测上限；不是全圈保证探测。

主动武器在自身导引头范围外只能使用有效航迹，失联沿最后位置飞行；半主动防空弹依赖发射平台持续雷达照射。超音速反舰弹速度更高、威力更强，但成本更高、弹药少、发射较慢。防空、近防、诱饵、燃油和补给库存都有限。命中和拦截使用可保存的确定性随机种子，武器以最多一秒子步长推演，防止高倍率穿越目标。

此模型增加了作战约束，仍是游戏抽象：真实型号仅记录公开定位，未建完整实装数据库；没有 3D、多人联机、逐弹道气动、完整雷达信号处理或舰载机甲板调度。高度切换、起降、声呐浮标与补给过程经过简化；海图不含山地高程。全部战局在浏览器运行。
