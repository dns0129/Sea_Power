# Sea Power · 海空战模拟平台

原创 2D 海空战策略沙盘，参考 [Sea Power 的传感器、海空协同、实时暂停与时间压缩玩法](https://store.steampowered.com/app/1286220/)。使用虚构海域和简化参数，不复用原游戏资源。

## 启动

macOS 双击 `启动海空战.command`。需要 Node.js 18 或以上版本，无须安装 npm 依赖。

```sh
npm start
```

打开 http://127.0.0.1:8789 。关闭启动终端或按 Ctrl+C 停止服务；端口冲突时使用 `SEAPOWER_PORT=8790 npm start`。

## 已实现

- Canvas 2D 海图：缩放、平移、坐标网格、海岸、探测圈、航点和历史航迹。
- 海图铺满整个视口，无页面标题栏；剧本、推演、舰队、单位控制、海图工具和记录均为独立浮动组件。
- 每个组件可展开/收起、拖动位置；底部控制台支持全部收起，本地记忆组件的收放状态。点击海图单位自动展开控制。
- 六类平台：驱逐舰、护卫舰、潜艇、战斗机、反潜直升机、攻击机；部署点、部署区域与撤回。
- 三个剧本：海峡交锋、深蓝猎潜、自由沙盘；自由沙盘可部署双方。
- 雷达、声呐、电子支援；传感器覆盖范围、风暴影响、高速声呐衰减、接触过期和最后已知位置。
- 单舰多航点、坐标输入、速度控制、水面编队跟随；水面/水下航路不允许穿越陆地。
- 反舰导弹、防空导弹、鱼雷；射程、目标适配、发射冷却、弹药、在途飞行、命中与损伤。
- 自动防空拦截、按本方探测结果行动的红方 AI、胜负结算、作战记录。
- 暂停、1/10/30/120 倍推演，本地战局保存和 JSON 导入/导出。

## 操作

1. 在部署阶段添加单位，点击海图放置；默认蓝方部署区位于西侧。
2. 选择蓝方单位，开启雷达。点击开始推演；声呐用于搜索潜艇，电子支援仅提供粗略接触。
3. 右键设置航点，Shift + 右键追加；也可使用“设置航线”或“坐标”。
4. 先选蓝方单位，再点击红方接触；武器满足目标类型、有效航迹、射程和弹药条件后即可发射。
5. 空格暂停/继续，Esc 取消指令。选定水面旗舰后可让其他水面舰跟随。
6. 使用底部控制台或组件右上角箭头收放组件；拖动组件顶栏调整位置。控制台本身也可收起。收放组件不会改变海图尺寸或镜头位置。

## 模型与边界

坐标单位为海里，速度单位为节，移动距离 = 速度 × 推演秒数 / 3600。传感器每 3 秒更新，连续 6 秒未更新视为失效航迹，90 秒后删除。传感器中断后保存最后已知位置；电子支援产生约 6 海里的粗略定位。雷达不探测潜航目标。

武器飞行以固定最多 1 秒的子步长更新；命中和拦截使用可保存的确定性随机种子。防空拦截简化为 22 海里内自动消耗防空弹药的概率判定。导弹制导、传感器地平线、燃油、舰载机起降和真实电子战尚未精细建模。第一版没有 3D、多人联机或真实装备数据库。

所有战局数据在浏览器内推演；保存功能只写当前浏览器 localStorage，导出 JSON 可迁移。页面可离线运行，在线字体不可用时自动使用系统字体。
